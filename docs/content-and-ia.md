# Content and Information Architecture

The production order is Hero → Who We Help → Featured Case Study release gate → What Are You Building → Why Intuise → Process → Trust → Intuise Games → Insights → FAQ → Contact → Footer.

Core content is English to preserve the existing public-language baseline. Language strategy remains a content-freeze TODO.

- Hero explicitly identifies Intuise, work types, audiences, and outcome.
- Who We Help is problem/outcome-based rather than an industry-logo list.
- Featured Case Study remains separate from Solution Finder and reuses only the client naming/visual already present before Astro; it adds no new metric or outcome while final approval remains open.
- Solution Finder has six typed directions and carries selection context to email.
- Trust uses working standards, not invented endorsements.
- Intuise Games is a single subordinate card with an email CTA because the final site URL is unknown.
- Insight cards are labelled “Editorial roadmap”; they are not represented as published articles.

Required approvals remain recorded in `ENC-PLAN.md` and `asset-inventory.md`.
