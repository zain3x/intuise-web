# Architecture

## Decision

Astro is the production framework with static output. No Netlify adapter is installed because the site has no SSR, API, form-processing, Function, or Edge Function requirement.

Static Astro components own layout, content, navigation, metadata, structured data, and all non-interactive sections. `SolutionFinder.tsx` is the only React island and hydrates with `client:idle`: it must be ready early enough for direct keyboard interaction while avoiding blocking initial page rendering.

## Data flow

`src/data/site.ts` supplies typed content. Astro renders static landing content. The Solution Finder receives the typed option array as props, maintains only selected-option state, and delegates safe mailto construction to `src/utils/mailto.ts`. A `<noscript>` fallback renders every option and contact link in static HTML.

## Routes and output

- `/` — landing page
- `/404.html` — static not-found page
- `/sitemap-index.xml` — generated by `@astrojs/sitemap`
- Static output: `dist/`

The archived Angular implementation is not compiled or published as runtime source.
